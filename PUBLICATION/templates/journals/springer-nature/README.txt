SPRINGER NATURE LATEX SUBMISSION SOURCES

The submission manuscript is manuscript.tex. It uses the official Springer
Nature sn-jnl class with the pdflatex, sn-basic, Numbered, and iicol options.

Compile from this directory:

  pdflatex manuscript.tex
  pdflatex manuscript.tex

The numbered bibliography is embedded in manuscript.tex for submission
portability. references.bib is included as the editable reference source.
The PDF figures used for compilation and their editable SVG counterparts are
included in the same directory. manuscript.qmd is the project master source.

Template provenance:
Springer Nature journal article template package, version 3.1, December 2024.
https://www.springernature.com/gp/authors/campaigns/latex-author-support

The target journal's Instructions for Authors take precedence over this
generic Springer Nature formatting profile.
