# Journal-specific templates

Create one directory per submission target. Do not alter the generic master
content simply to imitate a journal layout.

Each journal directory should record:

- journal name and current Scopus category/quartile check date;
- official author-guideline URL and access date;
- article type and word limit;
- required section order;
- anonymization and title-page requirements;
- official Word template as `reference.docx`;
- official LaTeX class/template when available;
- validated CSL file;
- figure/table placement rules;
- supplementary-data and code-availability requirements.

Quartile and author instructions must be rechecked immediately before
submission because both can change.
